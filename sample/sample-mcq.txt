Q1. A developer can write excellent Java code but has difficulty understanding customer needs, organizing teamwork, and managing changes. According to the chapter, what does this illustrate?
PDF page: 7
A. Programming ability alone is not the same as software engineering
B. Programming is more important than management
C. Software engineering is mainly about learning more languages
D. Customer communication is outside software engineering
Correct answer: A
Explanation: The chapter distinguishes programming from designing and engineering a complete software product. Software engineering also involves organization, management, communication, formalization, and human factors.
